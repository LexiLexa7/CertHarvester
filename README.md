# CertHarvester — Сетевой сбор и аудит СКЗИ КриптоПро и сертификатов X.509

CertHarvester — приложение для автоматизированного поиска, инвентаризации и учёта сертификатов электронной подписи (X.509) и лицензий КриптоПро CSP на локальном компьютере и в локальной сети с сохранением результатов в MS SQL Server 2019.

## Способ установки

- **На главном компьюетере:** установить программу с помощью установочного файла
- **На сканируемых компьютерах:** в powershell от имени администратора вписать данный код
 ```bash
  Set-Service -Name RemoteRegistry -StartupType Automatic; Start-Service -Name RemoteRegistry; reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v LocalAccountTokenFilterPolicy /t REG_DWORD /d 1 /f; netsh advfirewall firewall set rule group="File and Printer Sharing" new enable=Yes; netsh advfirewall firewall set rule group="Общий доступ к файлам и принтерам" new enable=Yes
  ```
  для того чтобы с главного компьютера был доступ к реестру с сертифекатами либо запустить .bat файл от имени администратора с готовым кодом.

## Основные возможности

- **Полный сбор сертификатов:** сканирование системных хранилищ Windows (`My`, `Root`, `CA`, `AddressBook`), прямое чтение бинарных слепков из реестра (Blob), извлечение сертификатов из контейнеров закрытых ключей КриптоПро (`header.key`) и поиск файлов (`.cer`, `.crt`, `.der`) в папках.
- **Анализ КриптоПро CSP и ГОСТ:**
  - Автоматическое определение установленной версии КриптоПро CSP (например, 5.0.13003).
  - Проверка ГОСТ-алгоритмов (`1.2.643.*`) и наличия встроенной лицензии КриптоПро внутри сертификата по OID `1.2.643.2.2.49.2`.
- **Умный сетевой радар:** автопоиск компьютеров в подсети с проверкой реального рукопожатия SMB2 по порту 445 (отсекает телефоны, роутеры и ложные отклики VPN).
- **Современный интерфейс и фильтрация:** тёмная/светлая тема, векторные иконки Lucide (вшиты в код без внешних файлов), фильтрация по клику на конкретный ПК слева и вкладки быстрой очистки от системных UUID.

## Режимы поиска устройств (SearchMode)

Для каждого сетевого узла поддерживается индивидуальная настройка области сканирования:

| Режим | Описание | Область поиска |
|---|---|---|
| 🔍 **Общий поиск (`All`)** | Комплексный аудит по умолчанию | Системные хранилища Windows + Реестр КриптоПро + Все добавленные индивидуальные каталоги |
| ⚙ **Стандартные пути (`Standard`)** | Быстрый системный сбор без обхода файловой системы | Только системные хранилища Windows и ветки реестра СКЗИ. Индивидуальные папки сохраняются, но отображаются неактивными и не опрашиваются |
| 📁 **Кастомные пути (`Custom`)** | Целевой файловый аудит | Поиск строго по указанным для данного компьютера директориям |

## Режимы работы приложения

1. **Графический интерфейс (WPF GUI)** — запускается флагом `-ui` или через пункт меню:
   - Адаптивная тёмная тема в стиле VS Code.
   - Кнопки быстрого скрытия/показа боковой панели и журнала в заголовке окна с динамическими иконками.
   - Сплиттер регулировки высоты консоли с двухпозиционной фиксацией (минимальный размер в 1 строку и полное скрытие).
   - Построчный скроллинг терминала колёсиком мыши без рывков.
   - Таблица сертификатов с автоматическим растягиванием по высоте и всплывающими подсказками (`ToolTipOpening`), если текст в суженной ячейке или заголовке обрезан многоточием.
   - Окно управления устройствами со специализированным полем ввода IPv4 (4 октета с валидацией) и автопоиском в подсети.
2. **Интерактивное консольное меню (CLI Menu)** — запускается при старте без аргументов:
   - Быстрый запуск сканирования, переход в консольное управление или открытие GUI.
3. **Режим автоматизации (CLI Batch / Silent)** — запуск по расписанию через Task Scheduler или PowerShell-скрипты.

## Консольные команды (CLI)

```bash
CertHarvester.exe [команда / флаги] [параметры]
```

### Основные режимы
| Команда | Описание |
|---|---|
| *(без параметров)* | Запуск интерактивного консольного меню |
| `-ui`, `--ui`, `-gui` | Запуск графического интерфейса пользователя (WPF) |
| `-help`, `--help`, `-h`, `/?` | Вывод полной справки по всем доступным командам |

### Сканирование и сбор СКЗИ
| Команда | Описание |
|---|---|
| `-scan`, `--scan` | Полное сканирование всех ПК и каталогов из `config.json` |
| `-target <host/ip>` | Сканировать конкретный компьютер или IP-адрес |
| `-dir <path>` | Рекурсивный поиск файлов сертификатов (`.cer`, `.crt`, `.der`) в папке |
| `-no-db` | Пропустить сохранение результатов сканирования в базу данных |

### Сетевая диагностика и радар
| Команда | Описание |
|---|---|
| `-discover [start_ip] [end_ip]` | Автопоиск компьютеров в подсети (Ping, проверка протокола SMB2, NetBIOS) |
| `-ping <host/ip>` | Экспресс-проверка узла: ICMP Ping + верификация реального SMB-ответа на порту 445 |
| `-netuse <host> <user> <pass>` | Проверка авторизации и монтирование сетевой сессии IPC$ |

### Работа с базой данных (MSSQL)
| Команда | Описание |
|---|---|
| `-db-test` | Проверить подключение к Microsoft SQL Server |
| `-db-export` | Экспортировать найденные сертификаты в БД |
| `-db-load` | Загрузить и вывести в консоль список сертификатов из БД |
| `-db-clear` | Очистить таблицу сертификатов в БД |
| `-server <address>` | Адрес сервера БД (например: `localhost` или `SRV\SQL`) |
| `-db <database>` | Имя БД (по умолчанию: `CertHarvesterDB`) |
| `-table <tableName>` | Имя таблицы (по умолчанию: `Certificates`) |
| `-conn <connectionString>` | Задать полную строку подключения к SQL Server |

### Управление устройствами в config.json
| Команда | Описание |
|---|---|
| `-list-nodes` | Показать список настроенных компьютеров и учётных записей |
| `-add-node <name> [ip] [user] [pwd]` | Добавить или обновить компьютер в конфигурационном файле |
| `-del-node <name>` | Удалить компьютер из конфигурации |

### Просмотр и экспорт отчётов
| Команда | Описание |
|---|---|
| `-list-certs` | Вывести список всех сохранённых сертификатов из `config.json` |
| `-export-csv <file.csv>` | Экспорт в CSV-файл (в кодировке UTF-8 с BOM для корректного открытия в Excel) |
| `-export-json <file.json>` | Экспорт в структурированный JSON-файл |

## Системные требования

- **ОС:** Windows 7 SP1 / 8.1 / 10 / 11, Windows Server 2012 / 2016 / 2019 / 2022.
- **Платформа:** Microsoft .NET Framework 4.5 или выше.
- **СУБД (опционально):** Microsoft SQL Server 2012–2022 (Express / Standard / Enterprise).
- **Сетевой доступ:** открытый TCP-порт 445 (SMB) и ICMP Ping на опрашиваемых узлах для удалённого аудита.
