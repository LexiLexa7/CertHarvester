# CertHarvester

Утилита для инвентаризации и централизованного сбора информации о сертификатах и лицензиях «КриптоПро CSP» в Windows-инфраструктуре.

CertHarvester сканирует локальные и удалённые компьютеры, системные хранилища сертификатов и заданные каталоги, извлекает данные о сертификатах, версии «КриптоПро CSP» и признаках встроенных лицензий, после чего сохраняет результат в базу данных Microsoft SQL Server.

Инструмент ориентирован на системных администраторов, ИБ-специалистов и аудиторов, которым нужен единый реестр криптосредств и сертификатов.

## Возможности

- Сканирование хранилищ сертификатов Windows:
  - `CurrentUser\My`;
  - `LocalMachine\My`;
  - каталогов профиля пользователя.
- Поиск файлов сертификатов `.cer` и `.crt` в локальных и сетевых каталогах.
- Подключение к удалённым компьютерам и сбор данных по сети.
- Определение установленной версии «КриптоПро CSP» через реестр Windows.
- Поиск признаков встроенной лицензии «КриптоПро» по OID-расширениям.
- Попытка идентификации удостоверяющего центра по издателю сертификата.
- Сохранение результатов в MSSQL.
- Автоматическое создание целевой таблицы при её отсутствии.
- Обновление существующих записей по серийному номеру сертификата без дублирования.
- Логирование процесса сканирования и ошибок.
- Графический интерфейс на Windows Forms.

## Требования

- Windows.
- .NET Framework 4.5.
- Microsoft SQL Server с доступом по сети или локально.
- Права на чтение хранилищ сертификатов и реестра.
- Для удалённого сканирования — сетевой доступ к целевым ПК и соответствующие права.
- Для анализа «КриптоПро CSP» — установленный «КриптоПро CSP» на проверяемых машинах, если требуется получать версию и лицензионные данные.
